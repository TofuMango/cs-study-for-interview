## 📌 학습 내용 요약

### <span style='background-color: #ede6b1'>[트리]</span>
- **`트리(tree)`** : 계층적인 구조를 표현하기 위한 자료구조
  - 트리의 핵심 구성요소
    - `노드(node)` : 데이터를 저장하는 구성요소
    - `간선(edge)=링크(link)` : 노드와 노드를 연결하는 구성요소
      
    ![](https://velog.velcdn.com/images/yjlee0006/post/90b5f703-29f6-47c2-a83c-86046f9c5c38/image.png)

| **용어** | **설명** |
| --- | --- |
| **형제 노드(sibling node)** | 같은 부모를 공유하는 노드 |
| **조상 노드(ancestor node)** | 부모노드와 그 부모 노드들 |
| **자손 노드(descendant node)** | 자식노드와 그 자식 노드의 자식 노드들 |
| **노드(node)** | 트리 자료구조에서 데이터를 저장하는 구성 요소 |
| **간선(edge)** | 트리 자료구조에서 노드를 연결하는 구성 요소 |
| **부모 노드(parent node)** | 어떤 노드의 상위에 연결된 노드 |
| **자식 노드(child node)** | 어떤 노드의 하위에 연결된 노드 |
| **루트 노드(root node)** | 트리의 최상단 노드, 부모 노드가 없는 노드 |
| **리프 노드(leaf node)** | 트리의 최하단 노드, 자식 노드가 없는 노드 |
| **차수(degree)** | 어떤 노드가 가지고 있는 자식 노드의 수 |
| **레벨(level)** | 루트 노드에서 시작해 특정 노드에 이르기까지 거치게 되는 간선의 수 |
| **서브트리(subtree)** | 트리에 포함되어 있는 부분 트리 |

- 서브트리 + 간선 + 레벨
![](https://velog.velcdn.com/images/yjlee0006/post/e4308b8a-e254-4199-9982-dbbe3694aaa3/image.png)

  -

### <span style='background-color: #ede6b1'>[트리의 순회]</span>
-**`트리의 순회(tree traversal)`** : 트리의 모든 노드를 한번씩 방문하는 순회
  - 순회의 종류
    - `전위 순회` : 루트 노드부터 시작해 왼쪽 서브트리를 전위 순회하고, 이후 오른쪽 서브트리를 전위 순회하는 방법
      
    ![](https://velog.velcdn.com/images/yjlee0006/post/a5882820-a899-408e-b52e-eb8b559aa8fb/image.png)

    - `중위 순회` : 루트 노드 기준 왼쪽 서브트리를 중위 순회한 다음, 루트 노드를 방문하고 오른쪽 서브트리를 중위 순회하는 순서로 노드에 접근하는 순회 방법
      
    ![](https://velog.velcdn.com/images/yjlee0006/post/4b200cff-1a77-4420-a281-6f937c0d5975/image.png)

    - `후위 순회` : 루트 노드 기준 왼쪽 서브트리를 후위 순회하고, 오른쪽 서브트리까지 후위순회한 다음, 루트 노드를 방문하는 순서로 노드에 접근하는 순회 방법
      
    ![](https://velog.velcdn.com/images/yjlee0006/post/e089192d-83e4-4a0c-b3cf-e3dacdee971c/image.png)

    - `레벨 순서 순회` : 가장 낮은 레벨부터 차례로 노드를 순회하는 방법
      
    ![](https://velog.velcdn.com/images/yjlee0006/post/9c59187a-6ec7-4647-a7f5-a8d5b46a1a12/image.png)

### <span style='background-color: #ede6b1'>[트리의 종류]</span>
### 기본적인 트리
-**`이진트리(binary tree)`** : 자식 노드의 개수가 2개 이하인 트리

![](https://velog.velcdn.com/images/yjlee0006/post/fae03bde-614a-496c-a42d-396f3b8d78a9/image.png)

-**`편향된 이진트리(askewed binary tree)`** : 모든 자식 노드가 한쪽으로 치우친 이진트리

![](https://velog.velcdn.com/images/yjlee0006/post/f556565e-99c5-4873-8ff7-af928a8f2608/image.png)

-**`정 이진 트리(full binary tree)`** : 자식 노드의 개수가 1개가 아닌 이진트리(자식노드 개수가 0이거나 2)

![](https://velog.velcdn.com/images/yjlee0006/post/ba2ac453-57f8-4c35-8823-44169a290bf6/image.png)

-**`포화 이진 트리(perfect binary tree)`** : 리프노드를 제외한 모든 노드들이 자식 노드를 2개씩 가지고 있고, 모든 리프 노드의 레벨이 동일한 이진트리

![](https://velog.velcdn.com/images/yjlee0006/post/120b2145-1769-41bb-9193-dd4cc4be4b2a/image.png)

-**`완전 이진 트리(complete binary tree)`** : 마지막 레벨을 제외한 모든 레벨이 2개의 자식노드를 가지고 있으며, 마지막 레벨의 모든 노드들이 왼쪽부터 존재하는 이진트리

![](https://velog.velcdn.com/images/yjlee0006/post/fbd65e06-c4c5-4df5-8cc8-a70830156b77/image.png)

### 탐색에 활용되는 트리
- **이진탐색트리** : 특정 노드의 왼쪽에는 해당 노드보다 작은값, 오른쪽에는 해당 노드보다 큰값 -> O(log n)으로 원하는 값 탐색 가능
- 
![](https://velog.velcdn.com/images/yjlee0006/post/6a1a387c-257d-4c1a-a7dc-7753a09a79fc/image.png)

💡 위의 경우 루트노드인 8보다 작은 왼쪽 서브트리의 노드는 볼 필요가 없음

<br>
- **힙** : 탐색에 특화된 완전 이진 트리의 종류 중 하나이며 최댓값과 최솟값을 빠르게 찾기위해 사용
  - 힙의 종류
    - `최대 힙` : 부모 노드가 자식 노드의 값보다 큰 값으로 이루어진 이진 트리
    - `최소 힙` : 부모 노드가 자식 노드의 값보다 작은 값으로 이루어진 이진 트리
    
    ![](https://velog.velcdn.com/images/yjlee0006/post/a4d0c762-7da7-4626-a2fe-2488013d4ac4/image.png)
    
  - `최대 힙` 구현 : 최상단 루트 노드는 언제나 우선순위가 가장 높은 값을 가지게 됨
    
  <br> =>  `우선순위 큐`
  
  ![](https://velog.velcdn.com/images/yjlee0006/post/fe8bcf52-1345-48a7-a52f-26a40ec4fe7c/image.png)
  
  💡 데이터를 빼낼 때 어떤 순서로 저장되었든 우선순위가 높은 데이터 순으로 얻어낼 수 있음

### 균형을 맞추는 트리
- 이진탐색트리의 문제점인 편향된 트리를 개선하기 위해 사용할 수 있는 특별한 이진 탐색 트리
  - `자가 균형 이진 탐색 트리`
  - `AVL 트리`
  - `RB 트리(자주 사용됨)`
  <br>
- RB 노드의 구성요소
  - `NIL(null leaf) 노드` : 실질적인 데이터가 저장되어 있지 않은 노드(리프노드)
  - 
![](https://velog.velcdn.com/images/yjlee0006/post/b8574688-57f6-4448-8df5-b9407eef6421/image.png)

<br>
- RB 트리의 규칙
  1) 루트 노드는 블랙 노드
  2) 리프 노드는 블랙 노드
  3) 레드 노드의 자식 노드는 블랙 노드
  4) 루트 노드에서 임의의 리프 노드에 이르는 경로의 블랙 노드 수는 같음
  +) 새 노드를 삽입 할 때는 삽입할 노드를 레드로 간주
  <br>
  -> 삽입 이후에도 RB트리가 유지되어야 하므로 4가지 조건에 부합할 때 까지 트리를 `회전` / `색상 재지정` 해야함
  <br>
  - `트리의 회전` : 양쪽 서브트리의 높이의 균형을 맞추기 위해 부모 노드와 자식 노드의 관계를 재 지정하는 것

### 대용량 입출력을 위한 트리
- **B 트리** : `다진 탐색 트리(한 노드가 여러 자식 노드를 가질 수 있는 트리)`의 한 종류
  - 특징
    - 한 노드가 가질 수 있는 자식 노드의 수는 최소, 최대 개수가 정해져 있음
    <br> 
    -> 최대 자식 노드의 개수가 M개인 B트리 : `M차 B트리`
    <br>
    -> `M차 B트리`가 가질 수 있는 최소 자식 노드의 개수 : `M/2(반올림)`
    <br>
    - B트리는 모든 리프 노드의 깊이가 같다
 - **B+ 트리** : B트리와 큰 골격은 유사하지만 아래와 같은 차이점이 있음
   - B+트리에서는 실질적인 데이터가 모두 최하위 리프 노드에 위치
   - B+트리에서 실질적 데이터가 저장되는 최하위 리프노드는 연결리스트의 형태를 띄고 있음
